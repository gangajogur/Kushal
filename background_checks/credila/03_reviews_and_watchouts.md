# 03 - Reviews and Watch-outs

Selection bias: unhappy borrowers post more. Treat the below as **recurring patterns**, not proof that every file fails.

## Recurring complaints (2024–2026 threads / consumer sites)
| Theme | What borrowers report |
|---|---|
| Processing chaos | Daily follow-ups; docs “not received” after submission; application “not in system”; grievance tickets closed without resolution |
| Slow subsequent disbursement | Year-2 / next-tranche fees delayed months; uni late fees; RM/office cannot access another city’s file |
| Insurance bundling | Life + travel/medical premiums (examples in threads: ~₹40k–₹1.5L combined); hard to remove; unclear if added to principal |
| Floating-rate rises | Rate increases even when borrowers expected stability/falls; disputes over resets |
| EMI / portal friction | Long delays to start or change EMI; ACH/mandate mismatches; IVR-heavy support |
| Fee before agreement | Processing fee debited before signed loan agreement; refund fights when student walks away |

Example threads/sites (see `07_sources.md`): r/Indians_StudyAbroad, r/fuckHDFC, inconsumercomplaints.com.

## What works when it works
- Faster sanction than many public-bank education-loan desks when documentation is complete (user reports often ~1–3 weeks; marketing/3P sometimes cite ~7–12 working days).
- Comfortable with large overseas tickets and broad cost coverage (tuition + living + related) when the profile fits.
- Advertised **no prepayment / foreclosure charges** (confirm in agreement).
- Direct disbursement to university (useful for fee proof if timed correctly).
- Dedicated RM quality is **person-dependent** — some students praise guidance end-to-end.

## Structural watch-outs (not just service)
1. **Floating rate + capitalised PSI** — 3-year Bachelor’s can grow the balance before EMIs; Australia EMI already heavy in family loan models (`Loan/`).
2. **Insurance push** — treat as a priced add-on; demand mandatory vs optional in writing.
3. **Disbursement SLA** — multi-year courses need year-2/3 tranches on time; get written turnaround + escalation.
4. **Brand ≠ bank** — “HDFC Credila” nostalgia does not equal HDFC Bank branch support.
5. **Aggregator conflict** — if routed via WeMakeScholars etc., compare the **same** Credila offer applied direct (`../wemakescholars/`).
6. **Tax benefit nuance** — Sec 129 / old 80E only under old tax regime per Credila disclaimer; CA confirmation for NBFC interest.
7. **Hard CIBIL pulls** — shopping multiple lenders carelessly can hurt co-applicant score/pricing.

## Bottom line on reviews
Credila is a mainstream specialised lender with real capacity to fund overseas study. Service and add-on-cost experiences are **inconsistent**. The family’s protection is a **written sanction** covering rate formula, fees, insurance, PSI schedule, and disbursement timelines — not website marketing or an aggregator’s verbal pitch.
