# Loan/

Education-loan and visa-application planning for Kushal. Four streams. Each `.md` names the script that produced it, and the scripts write into this folder using relative paths, so **run them from `Loan/` and do not move them**.

| Stream | Files | Script |
|---|---|---|
| Generic Rs 1.5 crore repayment table | `repayment_table_1.5cr.md`, `repayment_schedule_full.csv` | `calc_repayment.py` |
| 3-year course, staggered drawdown | `repayment_analysis_3yr_course.md`, `repayment_schedule_3yr_course.csv` (replaces the simpler model above) | `calc_repayment_3yr_course.py` |
| QUT loan fact-check (stays and works in Brisbane) | `QUT_loan_fact_check_report.md`, `qut_base_case_budget.csv` | `calc_qut_report.py` |
| Return-to-India scenarios (loan vs an Indian salary) | `QUT_return_to_India_scenario.md`, `APU_return_to_India_scenario.md` | `calc_qut_india_return.py`, `calc_apu_india_return.py` |
| QUT Genuine Student drafts | `GS_QUT_SOP_Khushal_draft.md`, `GS_QUT_july2027_pack.md` | none (written text) |

Key results (from the saved files; check the file before quoting)
- **QUT loan (stays and works in Brisbane):** minimum EMI about A$2,124 (₹1,41,950) a month; roughly break-even at A$70k income with shared rent. [`QUT_loan_fact_check_report.md`]
- **QUT, then return to India:** a ₹10–12 LPA metro job cannot cover the EMI (shortfall about ₹88k a month at ₹11 LPA); break-even about ₹25 LPA. [`QUT_return_to_India_scenario.md`]
- **APU, then return to India:** loan about ₹45.7 lakh, EMI about ₹59,233 a month; shortfall about ₹5.2k a month at ₹11 LPA; break-even about ₹11.05 LPA. [`APU_return_to_India_scenario.md`]
- A ₹1.5 crore loan would normally need collateral and a co-applicant (see `../background_checks/wemakescholars/`).

Notes
- The Genuine Student files target the **QUT July 2027** intake. The main assessment (`../report/FRESH_ASSESSMENT_2026-11-01.md`) plans for Feb/Mar 2027 first and lists July dates as a fallback. Keep the two consistent when the intake is decided.
- FX in these files: 1 AUD = ₹66.82; 1 MYR = ₹22.83 (APU file, 18 Nov 2026). Fees and rates may differ slightly from the report; the report's figures are in `../report/fresh/00_facts_register.md`.
- `__pycache__/` is generated by Python and ignored by git (see `.gitignore`).
