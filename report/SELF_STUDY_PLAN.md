# Self-study plan while he decides (saved 2026-11-01)
Profile (from user): absolute beginner (little/no coding), 20-30 h/week, budget open, focus = strong CS fundamentals, low-spec laptop. ISSE rejected (reason unknown). Costs/links verified by search 2026-11-01 unless marked.

## Principles
- Spine = CS50x (fundamentals); a game thread (Godot) keeps him interested; every phase ends with something he can show (GitHub repo + short demo).
- Low-spec laptop: use browser/cloud tools and Godot (4 GB RAM min, 8 GB recommended; OpenGL 3.3 'Compatibility' renderer works on old GPUs - https://docs.godotengine.org/en/stable/about/system%5Frequirements.html). Avoid Unity/Unreal/Unreal-C++ courses for now. A laptop upgrade may be the best paid item (opinion, not researched).
- Weekly rhythm: 4 days structured course, 1 day own project, 1 review/demo day (show a parent/mentor).

## Phases (about 12 weeks first stretch)
**Phase 1 (weeks 1-3): first programming, fast wins**
- CS50P - Intro to Programming with Python (Harvard, free; 10 weeks of material at 3-9 h/week, so ~2-3 weeks at 20-30 h; edX session runs to 31 Dec). https://www.edx.org/learn/python/harvard-university-cs50-s-introduction-to-programming-with-python
- GDQuest 'Learn GDScript From Zero' (free, browser, Godot 4) as a fun parallel. https://gdquest.itch.io/learn-godot-gdscript
- Output: 5 small Python programs + one tiny text/NPC-behaviour sim.

**Phase 2 (weeks 3-12): CS fundamentals**
- CS50x 2026 (free; 11 weeks; C first = memory, pointers, how computers work; then Python, SQL, web; final project). https://cs50.harvard.edu/x/ . Submit problem sets via edX account for feedback; free certificate. Verified certificate costs extra (price not checked).
- Optional gamified paid add-on: Boot.dev (interactive, XP/streaks; backend path ~12 months; includes 'Learn Memory Management in C', 'Data Structures & Algorithms in Python', 'Build an AI Agent'). Price conflict between Boot.dev pages: $33/month or $399/year (pricing page) vs $349/year (blog); 30-day money-back on pricing page; free tier is read-only. https://www.boot.dev/pricing . Backend/web-heavy, so treat as an experiment for 1 month, not core.

**Phase 3 (weeks 8-16, overlapping): game thread + C++**
- GameDev.tv 'Godot 4 2D Game Dev: Build 3 Games' (17.5 h; $14 on sale, normally $149; 30-day refund). https://gamedev.tv/courses/godot-2d
- CS50 2D (Lua/LOVE2D; free; after CS50x). https://cs50.harvard.edu/games/
- learncpp.com (free) from week ~10; target: re-write one small game in C++. https://www.learncpp.com/

**Phase 4 (months 4-6): the 'systems + AI' differentiators**
- Nand2Tetris (free) https://www.nand2tetris.org/ ; MIT 6.006 https://ocw.mit.edu/courses/6-006-introduction-to-algorithms-fall-2011/ ; MIT 18.06 https://ocw.mit.edu/courses/18-06sc-linear-algebra-fall-2011/ ; Berkeley CS188 Pac-Man projects https://inst.eecs.berkeley.edu/~cs188/su26/projects/ ; Game AI Pro https://www.gameaipro.com/ ; later LearnOpenGL (needs OpenGL 3.3 GPU) and Karpathy/fast.ai (see research/72_online_courses_and_prep.md).
