# Hochschule Darmstadt (h_da, campus Dieburg) B.A. Animation and Game - "Technology" specialisation
Sources: exam regulations (BBPO, 2023-06-27) https://h-da.de/fileadmin/h_da/Hochschule/Presse_Publikationen/Hochschulanzeiger/2024/FBMD_BBPO_AG_B_2023-06-27.pdf (full text cached, 900 lines) ; https://mediencampus.h-da.de/en/studying/study-programmes/bachelors/ba-in-animation-games/insight ; https://h-da.de/en/studies/study-programmes/study-programmes/architecture-media-and-design/animation-and-game . Accessed 2026-10-24. Confidence: high (primary regulation doc).

## Facts
- B.A., 7 semesters, English-taught, winter-semester start, admission by APTITUDE TEST (portfolio/technical test), study location Dieburg. Two specialisations chosen at application: "Technology" or "Art and Design". Public Hessian university: non-EU international students pay tuition? (verify: Hesse generally has no tuition fees; confirm for h_da; earlier note in 21_germany_shortlist covers fees).
- TECHNOLOGY track mandatory modules (5 CP each unless noted): Sem1: Game Programming 1, Algorithms and Data Structures for Games, Technical Art 1, Game Design, Basic Technologies 1, Methodology 1 (producing/production mgmt + design theory). Sem2: Game Programming 2, GRAPHICS PROGRAMMING, Technical Art 2, Methodology 2/sprint projects. Sem3: NETWORK PROGRAMMING, technical-art elective, project 3. Sem4: INDUSTRIAL PLACEMENT or STUDY ABROAD (30 CP). Sem5: AI AND BEHAVIOUR PROGRAMMING (mandatory), elective, project 5. Sem6-7: electives, R&D methods + game research project (15 CP), BACHELOR THESIS (15 CP).
- Key learning areas (official): game system design & software architecture; programming languages & graphics technologies; technical art & procedural content; generative AI & creative tools; back-end (networks, databases, client/server); shader development; game engines. Unity/C# primary; Unreal, C++, DirectX also used (per synthesis; verify).

## Fit to nephew
- STRONGEST German match on "AI for games + systems" within a games degree: a mandatory AI & Behaviour Programming module, ADS for games, graphics/shader programming, networking, built-in internship semester (a path to a studio in Germany), thesis.
