# Online courses / self-study to prepare for uni and career (2026-10-25)
Goal: cover the skills in the rubric (DS&A, systems/C++, maths, graphics, AI/ML, game-specific, projects) cheaply. All links verified live via search 2026-10-25 unless marked.

## Core programming and CS foundations
- CS50x (Harvard, free; certificate free) - C, Python, SQL, algorithms/data structures. https://cs50.harvard.edu/courses/ (prereq for CS50 2D/AI)
- CS50 2D - Intro to 2D Game Development (Lua + LOVE2D; 8 weeks; free; free certificate with >= 70% on assignments; term runs to 30 Jun 2027). https://cs50.harvard.edu/games/ . NOTE: old CS50G (Unity) was retired 30 Jun 2024.
- learncpp.com - free beginner-to-advanced modern C++. https://www.learncpp.com/
- MIT OCW 6.006 Intro to Algorithms (Demaine/Devadas; videos, notes, problem sets + solutions; free). https://ocw.mit.edu/courses/6-006-introduction-to-algorithms-fall-2011/
- Nand2Tetris (build a computer from NAND gates to Tetris; free self-study with online IDE; Coursera version is paid). https://www.nand2tetris.org/
- Computer Enhance / Performance-Aware Programming (Casey Muratori; assembly, CPU, cache, SIMD, multithreading) - NOT free: intro episodes marked paid (Substack subscription, price not checked). https://www.computerenhance.com/p/table-of-contents

## Maths
- MIT OCW 18.06 Linear Algebra (Gilbert Strang; videos, notes, problem sets, exams; free). https://ocw.mit.edu/courses/18-06sc-linear-algebra-fall-2011/ (also 3Blue1Brown Essence of Linear Algebra + Khan Academy - general knowledge, not checked this session)

## Graphics
- LearnOpenGL (free; needs basic C++ + some linear algebra; includes a small game walkthrough; free PDF). https://learnopengl.com/Introduction

## AI / ML
- Berkeley CS188 Pac-Man projects: search (DFS/BFS/UCS/A*), minimax/expectimax, reinforcement learning, Bayes nets/HMMs, perceptron/neural nets; Python; starter code + autograder free. https://inst.eecs.berkeley.edu/~cs188/su26/projects/ and https://ai.berkeley.edu/project_instructions.html (do not post solutions)
- CS50 AI (Harvard; free; follow-up to CS50x). https://cs50.harvard.edu/courses/
- Andrej Karpathy Neural Networks: Zero to Hero (free; from backprop to GPT; needs Python). https://karpathy.ai/zero-to-hero.html
- fast.ai Practical Deep Learning for Coders (free; needs ~1 yr coding; PyTorch). https://course.fast.ai/
- Andrew Ng / Stanford Machine Learning Specialization (Coursera; $0 to view/audit each course individually via "Audit the course" link; certificate $49/month; the Specialization page may hide audit). https://online.stanford.edu/courses/soe-ymls-machine-learning-specialization

## Game AI specifically
- Game AI Pro (chapters free as PDFs: behavior trees, utility AI, FSMs, pathfinding, A* optimisation, '1000 NPCs at 60 FPS', etc.; do not redistribute). https://www.gameaipro.com/

## Full online degree alternative (for the 'non-university' cost question)
- University of London BSc Computer Science (Games Development specialism, with Goldsmiths; delivered on Coursera). 36-72 months; GBP 14,666-21,829 total depending on country band; India = Band A: web-supported GBP 14,666 + 18% GST (~GBP 17.3k = ~Rs 22 lakh at 127.13). Entry: age 17+, English requirement, GCSE Maths 9-5 / AS Maths A-E or equivalent (or performance-based route). Sessions: apply 21 Oct 2026 - 17 Mar 2027 (start Apr 2027); next apply 28 Apr - 8 Sep 2027 (start Oct 2027). Modules include Intro to Programming I-II, Computational maths, Discrete maths, How computers work, OOP, ML & neural nets electives, mobile, physical computing/IoT, final project. https://www.london.ac.uk/study/courses/undergraduate/bsc-computer-science ; https://www.coursera.org/degrees/bachelor-of-science-computer-science-london/tuition-financing
  Caveats: no campus life, no student visa, no fresher-recruitment pipeline; recognition for Japanese/German immigration/Master's NOT verified.

## Suggested 12-month roadmap (draft)
1. Months 0-3: CS50x (or skip if already programming) + learncpp + MIT 18.06 -> goal: first C++ project.
2. Months 3-6: CS188 Pac-Man projects (search, minimax, RL) + CS50 2D; finish Nand2Tetris first half.
3. Months 6-9: LearnOpenGL + Game AI Pro reading; build a small game with behavior trees/utility AI NPCs.
4. Months 9-12: Karpathy/fast.ai/ML Specialization for ML; portfolio (3 projects on GitHub) usable for h_da portfolio exam, KAIST essays, ISSE/Aizu labs.
